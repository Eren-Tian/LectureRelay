# 本地字幕延迟验证 — 0.3.6

## 素材与范围

使用 [MIT OCW 9.00，Fall 2004，Lecture 1](https://ocw.mit.edu/courses/9-00-introduction-to-psychology-fall-2004/resources/mit9_00f04_lec01_trimmed_mp4/)，Jeremy Wolfe 的原始课堂音频 01:00–02:30。90 秒片段只裁切、混为 mono 并重采样到 16 kHz，未使用机器朗读或改变语速。来源、哈希和转换记录在 `target/local-latency/audio/provenance.json`。后续真实声音验收遵循[素材政策](audio-sources.md)。

2026-10-05，在当前台式机的真实 Tauri debug EXE / React / WebView2 中测试。应用在竖屏上运行，只使用 `target/classroom-fixes/ui-1` 的隔离库。Nemotron Streaming EN 0.6B、Hy-MT2-1.8B Q4_K_M 与 Quiet Mode 开启，云端 provider 为 `none`。没有付费 API 或上传课堂内容。对照使用相同课程背景、模型、音频和系统音频设备；约 200 ms 采样一次原生状态和实际 DOM，录音中未并发编译或运行重型测试。

时间从源音频播放开始计算，包括冷加载、原句开始位置、定稿与采样等待。不是逐词声音到字幕延迟。定稿到保存只有改动前 4、改动后 5 个录音中可观察的样本；停止后的最后一段由最终数据库另行检查。不能把小样本 p95 当作稳定服务承诺。

两份录音的全部声明帧均可读取，应用丢弃缓冲与采样数均为 0。系统音频设备各报告 1 次不连续事件，警告保留在回放页；设备没有提供实际受影响时长。开头、中间、结尾五处 10 秒 RMS 包络相关性分别至少 0.988 与 0.996，未观察到对齐漂移。有限检查不能保证每个声音样本完全相同。

模型两次输出词序约 97.65% 一致，定稿边界和少量词有所变化，其中仍观察到边界附近的词截断。模型间一致度不是对照真实原文的 WER，也不是翻译准确率。没有为了更快显示新增强制定稿边界，现有 20 秒上限的准确性限制仍需后续解决。

## 真人音频的麦克风检查

`mit-microphone` 使用真实麦克风拾取扬声器播放的同一片段。415 次观察中，首次英文 / 临时中文 / 已保存中文为 2.33 / 16.23 / 24.05 秒；积压中位数 1.09 秒、峰值 3.27 秒，最大最终队列 1，无延后翻译，最终 5 / 5 段均保存译文。

90.28 秒、4,333,440 个 mono 48 kHz 帧全部可读取。设备不连续、应用丢弃缓冲与采样均为 0。声学录音与源文件包络相关性只有约 0.56–0.68，不能沿用直接系统音频的 0.8 阈值宣称逐段完整匹配，也不能由此给出课堂准确率。这只验证当前房间和设备的短时流程。证据：`target/local-latency/microphone-summary.json`。
