# LectureRelay 0.3.10 — 实时课堂要点与界面精简

- 从 0.3.8 升级新增可选实时课堂要点：默认关闭，启用后默认每四分钟整理新定稿英文，可选两分钟、五分钟或手动整理。卡片保留原文、时间范围和引用，手写笔记独立保存。
- Groq 为优先提供的可选云端入口，也支持 OpenAI。设置包含获取 Key、保存、实际生成测试、文字上传说明与启用；总结设置不改变本地识别和翻译。录音保存不等待总结完成。
- 为降低课堂功耗，移除本地 Qwen 实时分段总结选项及其原生推理路径。保留 Groq、OpenAI 与关闭选项，默认仍不启用。
- 升级时，旧的本地实时总结设置自动变为关闭，并清除该功能的文字上传同意。不会自动切换到云端，也不会上传旧卡片或转录。已明确配置的云端总结保持原设置。
- 旧版界面或请求也不能重新启用本地实时总结。已有卡片、时间戳引用、原文、手写笔记与模型文件保留。
- 本地英文转录、翻译及手动执行的课后复习、问答保持原设置。无需下载 Qwen 即可使用云端实时总结。
- 设置入口改为齿轮，删除课程、字幕、总结、时间索引和笔记中的常驻解释文案。零条待翻译不再显示；实际任务状态、错误与确认提示保留。

本轮只做静默回归与安装包验证，不播放音频、不发起额外云端请求。此前真实 Groq 验收及 Qwen 资源开销见 [0.3.9 验收记录](https://github.com/Eren-Tian/LectureRelay/blob/0c59144aa950e213def3c5f2b4df441bdcbffadc/docs/testing/live-summaries-v0.3.9.md)；该记录是历史测试结果，不能代表 0.3.10 已重新跑过课堂音频测试。

发布附件来自 [干净 Windows 构建](https://github.com/Eren-Tian/LectureRelay/actions/runs/37482591168)，实际 NSIS 安装、payload、原生资源、图标与许可校验通过。随附 `build-metadata.json` 记录该 CI 安装包的源码、工具链、大小、哈希和测试范围。此前实机设置验收使用精简界面前的本地编译包；最终界面另通过中文与实时总结 React 组件测试，发布的 CI 附件未重跑真实课堂或长时验收。发布源码的 [Windows checks](https://github.com/Eren-Tian/LectureRelay/actions/runs/37482591546) 与打包分开执行。
