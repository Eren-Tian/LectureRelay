# LectureRelay 0.3.13 — 处理方式回退修正

- 修正 0.3.12 的一处设置读取问题：已保存 Groq 或 OpenAI 服务时，若偏好设置中“课堂翻译”或“课后学习”的处理方式是当前版本无法识别的值，0.3.12 会把它误当作旧版本缺少的字段，改为云端处理；配置了 API Key 时，后续文字可能被上传。现在无法识别的处理方式一律回退为本地，只有旧版本确实没有该字段时，才沿用原先明确选择的云端服务。新增回归测试，覆盖无法识别的值、空值和类型错误。
- 开发文档更正：安装包验证脚本会安装到日常使用的 `%LOCALAPPDATA%/Programs/LectureRelay`，并非隔离的临时目录。

运行安装包即可升级，课程、课堂记录及下载的模型会保留。此版本仍为未签名的开发预览版。数据库结构、模型版本和第三方依赖均未改变。
