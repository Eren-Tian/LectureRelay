# 开始使用 LectureRelay

安装 Windows EXE 即可使用，无需安装开发工具、Python、CUDA、Ollama 或 FFmpeg。首次安装时，如果电脑缺少 WebView2，安装器会联网下载。

以下操作对应 **0.3.17 中文界面**。运行新安装包即可升级，已有课堂资料和下载的模型会保留。

从 0.3.10 升级时，设置入口的位置变化如下：

| 0.3.10 安装版                  | 新设置界面                          |
| ------------------------------ | ----------------------------------- |
| 首次使用                       | 首次设置                            |
| 通用                           | 通用                                |
| 声音 / 字幕显示                | 声音与字幕 → 声音设备 / 字幕样式    |
| AI 服务                        | AI 与模型 → 处理方式                |
| 本地 AI                        | AI 与模型 → 本地模型                |
| 实时总结                       | AI 与模型 → 课堂要点                |
| 安全与隐私中的 Key 管理        | AI 与模型 → 处理方式 → 云端 API Key |
| 数据与存储 / 安全与隐私 / 关于 | 原入口保留                          |

1. 打开 **设置 → 首次设置**。可选“仅英文原文”或“英文原文 + 译文”。到 **AI 与模型 → 本地模型** 下载所需模型，返回首次设置，点击 **启用本地英文字幕** 或 **启用本地双语字幕**。模型只需下载一次，所有课程共用；课后总结使用的 Qwen 可以稍后下载。
2. 点击 **选择设备并测试声音**。线下课堂用 **麦克风**，电脑播放的课程用 **系统声音**。先完成 5 秒声音测试；当前不支持混合录制麦克风与系统声音。
3. **新建课程**，选择译文语言（共 20 种，含简体和繁体中文、日语、韩语、越南语、泰语、西班牙语、法语等）。补充课程背景和专业术语后，点击 **开始录音**，确认声音来源、设备与字幕方式。
4. 英文字幕随识别更新，译文在句子定稿后显示。向上滚动可查看前文，点击 **回到最新字幕** 继续跟随。**独立字幕窗** 可以单独关闭，录音继续。若英文识别持续落后，可 **切换到全速模式**，或 **暂停翻译**，让英文识别优先处理。录音设备中途断开时，会自动切换到系统默认设备，继续录在同一节里，回放时这一处会提示检查。没有可用设备时，已录部分会保存，点击 **保存并继续录音** 可换一个设备接着录（新的一节标题带“（续）”）。
5. 课堂结束时点击 **结束并保存**。录音先保存，剩余字幕或翻译会显示独立的处理状态。回放时按空格播放/暂停，←/→ 快退快进 5 秒；转录会跟随播放滚动。超过 30 秒没有文字的地方会标出时间段，录音末尾还没转写的部分也会标出，点时间可以直接听这一段。选中一段文字可以 **问 AI**，较短的词语还可以 **加入术语表**。把鼠标移到某段转录上，可以给它标注 **讲话人**（老师、同学或自定义名称），也能把某个讲话人统一改名；下载可选的讲话人识别模型（约 140 MB）后，点击 **识别讲话人** 可以自动标注，手动起的名字会保留。导出的字幕和转录会带上讲话人。下次打开时可 **从上次位置继续**，首页的 **继续学习** 也会列出没听完的课。可以修订文本、补全翻译，也可以导出 Markdown、JSON、SRT 或 VTT。已有的音视频文件可以直接拖进首页或课程页导入。课程平台提供文件下载链接时，也可以在导入窗口粘贴这个 https 链接，应用会下载后导入；YouTube 等视频网站页面不支持。
6. 下载 Qwen 后，待实时处理结束，使用 **生成 AI 草稿**、**笔记 → 整堂复习** 或 **问答**。笔记支持标题、列表、待办、表格等格式，可用工具栏或 Ctrl+B / Ctrl+I，Ctrl+S 保存。预览时可在 **文档**、**导图** 和 **自测** 之间切换：导图按标题和列表的层级画出笔记结构；自测把每个带内容的标题做成一张卡片，先回想再显示内容，标为"记住了"或"再看看"，一轮结束后可以只重练没记住的。AI 草稿和复习指南保存在 **历史版本** 中，由你决定是否采用；已有手写笔记会保留。

首次安装可直接录音，配置字幕后才会运行语音识别。升级会保留已有偏好。没有模型或 API Key 时仍可录音和手动编辑；本地 AI 失败不会自动切换到云端。**安静模式** 对所有本地 AI 共用的 CPU 预算生效，关闭后允许使用全部可用 CPU 核心。译文仍可能落后数秒或更久，英文进度提示不代表翻译延迟。参见 [本地 AI 与质量限制](local-ai.md)。

需要边录边整理课堂要点时，打开 **设置 → AI 与模型 → 课堂要点**，按 **获取 Groq API Key → 保存 Key → 测试连接 → 勾选上传说明 → 开启课堂要点** 完成配置。上课时也可以在课堂页的 **课堂要点** 中点击 **开启课堂要点**。此功能默认关闭，也可选择 OpenAI；仅影响总结，不改变本地字幕和翻译设置。0.3.10 已停用本地 Qwen 实时总结，课后手动复习与问答仍可使用 Qwen。详见 [实时总结说明](live-summaries.md)。

日常使用的外观和安静模式在 **通用** 中，修改后自动保存。声音来源在 **声音与字幕 → 声音设备**，字幕字号和排版在 **字幕样式**。识别、翻译及课后学习模型在 **AI 与模型 → 处理方式** 中分别选择；只有修改了需要保存的偏好，页面底部才会出现 **保存修改**。云端 Key 管理位于该页折叠的 **云端 API Key** 中。

删除一节课时，在课程历史或回放页点击 **删除课堂记录** 并确认，这一节课的录音和学习资料会被永久删除，其他课堂记录、课程背景、术语表和 PDF 保留。在课程页点击 **删除课程**，课程立即移入 **回收站**，提示条中的 **撤销** 可以马上恢复；之后也可以在 **设置 → 数据与存储 → 回收站** 恢复或永久删除。**清空数据与模型** 会删除全部课程和已下载模型，需要输入 **清空** 确认，请先导出需要保留的内容。

卸载应用会保留课堂资料。备份前请退出应用，并同时保存数据库和资料库。课堂内容未使用应用层加密。更多说明：[本地识别](local-speech.md)、[可选云端服务](../providers/setup.md)、[存储位置](../architecture/overview.md)、[质量评测](https://github.com/Eren-Tian/LectureRelay/blob/0c59144aa950e213def3c5f2b4df441bdcbffadc/docs/testing/local-ai-v0.3.md)。
