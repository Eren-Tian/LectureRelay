# LectureRelay 0.3.14 — 工作流可靠性与代码整理

- 补全转录时，按“语音识别”所选服务判断是否需要确认上传或补充 API Key，不再受“课堂翻译”“课后学习”所用文字服务的影响。
- 实时总结：响应较慢时不再重复发起读取；较早返回的旧结果不会覆盖已完成的新卡片；生成失败的提示在之后的正常刷新中仍会保留。
- 笔记草稿：离开并重新打开笔记后，未保存的草稿能及时恢复，多次保存按顺序写入。
- 原生错误改用固定错误码，界面依据错误码显示提示并决定恢复方式，例如服务商暂时不可用时提示稍后重试。
- 内部整理：
  - Rust 代码启用统一的检查规则，正式代码不再使用出错即崩溃的写法；每处直接调用 Windows 接口的代码都写明了安全依据。
  - 读取 CPU 信息时传给 Windows 的缓冲区长度改为与实际分配一致。
  - 界面样式按功能拆分为多个文件，删除不再使用的样式，主题颜色改用 `light-dark()` 成对定义。改动前后，各测试界面状态下所有元素的计算样式完全一致，外观没有变化。
