# 设置界面与工程规范审查 — 2026-10-06

本轮基于 `b9c2d4a` 后的 0.3.11 开发工作区。优化设置的分类、布局和状态管理，并检查现有类型约束、模块边界、错误处理、迁移、凭据及构建测试规范。本记录不等同于独立安全审计，也不包含课堂模型质量或长时性能验收。

## 已实现

- 六个主分类分成“日常使用”和“应用管理”；首次设置独立保留。已配置字幕的用户默认进入通用，新用户默认进入首次设置。
- 声音设备与字幕样式合并到一个主分类，分别显示；AI 功能设置、模型下载和实时总结集中到另一个主分类。云端 Key 与高级参数默认折叠。
- 模型选择按英文字幕、课堂翻译、课后学习分组；仅选用云端文本功能时才显示其服务配置。实时总结继续独立配置。
- 外观和安静模式标注自动保存；共享偏好仅在有修改时显示保存栏。只读页面不再长期显示禁用的保存按钮。相关功能的设置跳转直接落到对应位置。
- 设置导航使用稳定标识，不把中文文案作为程序状态。拆分导航、页面、模型/凭据、存储、隐私、各项表单及资源加载；子组件只接受所需资源字段。

## 工程检查

- TypeScript 保持 `strict`、未使用变量/参数检查和 switch 检查；IPC 类型继续集中在 `types/domain.ts`。
- Rust 普通测试：桌面 **81 通过、0 失败**，环境检查 **1 通过**；要求模型、硬件和真实 Windows 凭据的测试保留为 opt-in。
- Clippy 全工作区、全部 target、`-D warnings` 通过；Rust 格式、Prettier、生产前端构建与原生运行资源校验通过。
- 八组 React 回归覆盖课堂要点、模型管理、笔记保存、字幕、明暗对比度、中文界面、新设置状态和实时总结。使用隔离的模拟 IPC；不读取用户真实课堂库或 Key，不播放声音，不执行真实云端请求。
- 仓库扫描检查本地文件、导入依赖及文档链接。未发现循环/失效导入或命中的凭据模式；模式扫描不能证明不存在秘密或安全问题。
- 检查了原生设置命令的任务互斥及对运行时/总结偏好的保留；模型、凭据、HTTP、SQLite 与存储清理保持各自职责。未改动已发布 SQL 迁移或相关原生行为。
- 贡献指南补充实际 React 回归命令；仓库结构说明补齐 study、library、local-text、CI 和新的设置分工。

本机结果位于 `target/settings-review/components.json`；界面截图位于同一目录，使用合成数据。相关自动化为 `tests/e2e/settings-components.mjs`，由 `pnpm test:components` 和 Windows CI 统一执行。
