# LectureRelay v0.2.0 — classroom preview

Date: 2026-09-30. Windows x64, current-user English NSIS installer. This preview implements the classroom path and native local STT, with acceptance limits below. It is not certified ready for every 90–180-minute classroom.

## Local model decision

Investigated Nemotron Streaming EN 0.6B, Moonshine Streaming Small, Parakeet TDT 0.6B v3, Qwen3-ASR 0.6B, Fun-ASR-Nano 2512 and Whisper. Actually measured the first three plus Whisper tiny.en; Nemotron CPU/CUDA and glossary comparisons were separate runs. Qwen/Fun were documentation-only investigations.

Recommended uses Nemotron Q8_0 and NeMo-Speech.cpp 0.1.0, in a controlled C++ worker with CPU DLLs and a Windows Job Object. The installed app needs no Python/Conda/pip/PyTorch/CUDA. One global 667.45 MiB weight file downloads after install; weights are not bundled. NVIDIA's conditional model license and notice are supplied, along with the SDK's full upstream notices. Source-wide licensing/signing remain public-release tasks.

On a 175-word mostly synthetic set, selected native WER was 6.29%; Parakeet 6.29%, Moonshine batch 8.00%/stream 17.14%, Whisper tiny.en 8.00%. Exact technical phrase misses were 4/17 for selected native Nemotron; boost 3 produced identical transcripts. These are small-set results, not a general lecture accuracy claim. See [benchmark](https://github.com/Eren-Tian/LectureRelay/blob/0c59144aa950e213def3c5f2b4df441bdcbffadc/docs/testing/local-stt-benchmark-v0.2.md) and [ADR](../adr/ADR-0002-local-speech-recognition.md).

## Long session and resource scope

The actual paced native-worker/WAV/SQLite soak ran **5400.6 wall seconds**, saved **5357.0 seconds of audio and 419 finals**, with zero duplicate IDs, dropped STT chunks or recognition errors. Two ten-second pauses were excluded from audio; checkpoints matched finalized WAV. CPU mean/peak were **3.82% / 5.21%**, RAM peak **1019.25 MiB**, per-feed STT compute mean/peak **562 / 1562 ms**. This scope includes the developer harness/native worker and simulated translation queue delay, excluding React/WebView2, CPAL capture and real translation.

Short native CPU tests measured about **943 MiB** worker RAM, **11.92%** active normalized CPU, **526 ms** mean feed computation and RTF **0.2786**. First partial is estimated at ~2.58 seconds plus checkpoint/poll/UI delay; final/p95 screen latency is unmeasured. CUDA CLI ran successfully at RTF **0.0507** and ~229 MiB host RAM; process-attributed GPU utilization/VRAM were not measured and GPU mode is not shipped. The i9/4090 machine cannot validate ordinary-laptop fan/power behavior. No 180-minute/full-UI classroom result exists.

## Storage, migration and uninstall

Database: `%LOCALAPPDATA%/LectureRelay/app.db`. Models/state/recovery/logs stay under that root; recordings/sidecars stay under the Windows Documents `LectureRelay` library. Credentials retain the v0.1 targets. Migration 2 adds soft deletion, audio source, provider/status/version metadata, model registry and transcript edit history without deleting existing records.

Uninstall retains database/library/models/credentials. Back up database and library after exit. Trash restore is supported; no permanent purge/import/history browser is present. Course content is not encrypted.

## Installer and remaining acceptance

Installer: `target/x86_64-pc-windows-msvc/release/bundle/nsis/LectureRelay_0.2.0_x64-setup.exe`; adjacent `.sha256` identifies the final build. Unsigned, English, per-user; WebView2 bootstrapper may require network if missing. Native SDK is bundled, model download is separate.

Full UI automation was explicitly stopped by the user with the physical Escape key during final isolated acceptance. No further UI input was performed. English home/Settings content was inspected, but complete live/model-manager UI acceptance is not claimed. Prior window activation/capture failures also limited visual evidence. Native download/cancel/install/load/remove and actual device checks passed separately.

Also outstanding: real-key cloud calls, ordinary-laptop/real-room measurements, full-app 90–180-minute sessions, device unplug/disk-full acceptance, local translation and traceable second-engine refinement. Startup explicitly shows the main window before focusing to handle launches inherited from a hidden build shell; this final visibility adjustment is included in packaging, but its UI acceptance was interrupted.

Stop preserves recording promptly, but queued translations can keep live work active while requests drain; edits/new jobs remain gated. The native endpoint heuristic can split sentences. Installed status checks file length/manifest rather than rehashing on each run. These are known preview limits, not hidden completed features.
