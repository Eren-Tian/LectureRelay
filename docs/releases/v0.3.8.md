# LectureRelay 0.3.8 preview

本版本保留实际 0.3.7 的中文界面、清晰的模型下载状态、可关闭重开的字幕窗、单课堂删除和可恢复复习，继续优化本地 Nemotron + Hy-MT2 的课堂字幕。

- 本地识别更新间隔从 640 ms 缩到 320 ms，500 ms 句尾静音按连续采样累计，避免更新变快后提前拆句。
- 稳定的临时翻译前缀从 32 词扩到最多 80 词；长句后半可以继续更新。修订身份、过期结果拒绝、最终任务优先和有界队列保留。
- 实时翻译使用 4,096 token 上下文和更短提示；课后任务保留 8,192。全零输入且未进入语音段时跳过识别编码，录音与非零低音量仍保留。
- 可选诊断记录准备、执行、修订和真实 UI 出现时间，避免混用首个片段和完整含义的延迟。

同一五分钟 MIT 自然课堂、安静模式的安装版暖启动对照：首英文约 2.17 → 2.33 秒，中文课程主题约 9.10 → 6.68 秒，完整对比含义约 9.33 → 8.97 秒；最大英文积压 2.07 → 1.87 秒。首英文没有明显提速，不能用不同原文长度的首条最终译文宣称大幅改善。播放前静音 CPU 明显减少，讲话期间 CPU 仅小幅降低。

真实麦克风测试有明显漏词，首英文约 9 秒；翻译仍有术语、主语和数字维度错误。日／韩检查仅验证功能连接。最终同素材完整冷启动复测未完成；用户要求先不做新的 90 分钟验收。此包是短测预览，不是完整课堂准确性、长时或普通笔记本验收通过的版本。

下载 EXE 安装即可，无 LectureRelay 账号、Python/Conda/CUDA 或 GPU 要求。本地模型在应用内另行下载；不自动回退云端，不包含实验 Mozilla 权重。安装包未签名。升级保留课堂资料，已有 Release 资产不覆盖。
