# LectureRelay 0.3.6 — 本地字幕与翻译流水线

本地英文识别的读取间隔从 2 秒缩短为 640 ms。本地翻译在课堂开始时加载模型，识别中的稳定片段先生成临时译文；完整句子的译文也逐步上屏。仍使用 Nemotron 和所选本地翻译模型，不需要 LectureRelay 服务端，不增加云端请求或费用。

完整句子优先处理。待处理的临时片段只保留最新一份；过期的在途临时请求可取消并保留已加载模型。最终翻译仍有队列与超时上限，跟不上时保存英文并留待课后重试。识别积压时，翻译让出资源。

主窗口与字幕浮窗显示“临时译文 · 将随原文调整”或“翻译中…”。原文修订、目标语言变化或课堂切换后，旧结果不能覆盖当前字幕。只有完成且仍与原文匹配的最终译文进入课堂记录和导出。向上阅读时，逐步增长的译文不会把阅读位置拉回底部。字幕浮窗只新增订阅与取消订阅事件的最小权限。

录音独立保存，保持每秒的持久化检查点。没有通过跳过音频或新增更短的强制定稿边界来降低显示延迟。Quiet Mode 继续为全部本地 AI 提供共享 CPU 预算。现有可选云端配置保留，新增的临时片段翻译只用于本地模式。

采用 [MIT 真人课堂片段](../testing/audio-sources.md)验证，见 [测试范围与结果](https://github.com/Eren-Tian/LectureRelay/blob/0c59144aa950e213def3c5f2b4df441bdcbffadc/docs/testing/local-caption-latency-v0.3.6.md)。首次临时译文提前不等于逐词实时翻译；冷加载和长句定稿仍需等待，模型仍可能识别或翻译错误。

本版本包含 0.3.5 中文界面与 0.3.4 课堂控制修复。这是本地候选版本，GitHub 发布状态以 Release 页面为准。
