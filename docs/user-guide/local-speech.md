# Local speech recognition

The Windows app supports one local English speech model: **Nemotron Speech Streaming EN 0.6B Q8_0**, with the pinned NeMo-Speech.cpp CPU runtime. Alternative speech models have not passed acceptance.

Use **设置 → AI 与模型 → 本地模型** to download Nemotron, then choose **本地英文识别** in **AI 与模型 → 功能设置 → 英文语音识别**. The **首次设置** checklist can also enable local captions after download. The 699,872,960-byte download (667.45 MiB) is shared across courses in `%LOCALAPPDATA%/LectureRelay/models`. Progress/cancel, model details and removal are available. Active lecture/work blocks downloads/removal; starting never downloads automatically.

Integrity uses SHA-256 `d9a01898d2a611c8764e23a1c2f45e70bbd5a425dc4de93692ac951dd603812d`, official revision `ebe59e5a817142986528bbbee5dba8db7b38ed50`. License/notice are saved beside weights. Failed/cancelled downloads are not marked installed; cancellation is checked at 250 ms intervals while network I/O is pending and retries restart the download.

Packaged C++/CPU DLLs require no Python/PyTorch/Conda/CUDA. In **设置 → 通用**, turn **安静模式 (Quiet Mode)** on to limit the shared local AI CPU budget, or off to allow the full CPU budget. This global preference saves immediately and also updates recognition already running. Provisional text can change before finalization. UI timestamps are coarse spans, not word-level alignment. Current caption behavior and latency evidence are documented in the [local AI guide](local-ai.md) and [real lecturer tests](https://github.com/Eren-Tian/LectureRelay/blob/0c59144aa950e213def3c5f2b4df441bdcbffadc/docs/testing/local-caption-latency-v0.3.6.md).

**通用** also offers Light and Dark appearance, saved automatically across restarts. **声音与字幕 → 声音设备** and the Start Lecture dialog have a five-second input test with a live level meter; it uses the selected microphone or system output without saving or uploading audio. Replay supports 0.5–2× speed, ten-second skips and English/translation search. Clear search restores the complete transcript; exports always include all segments.

Up to 64 course source glossary terms become RNNT speech contexts at boost 3. The benchmark observed no improvement; course descriptions are not free-form local ASR prompts. The same engine processes unsaved audio after Stop in 30-second batches, with no separate refinement workflow.

Failures/timeouts stop captions while capture continues; backlog remains on disk. Earlier v0.2 measurements recorded about 943 MiB native RAM in the CPU benchmark, a 936 MiB speech-worker peak in the installed 90-minute run, and continuing WebView2 memory growth. These figures apply to that build, not a new 0.3.11 long-session test. Ordinary-laptop fan/power behavior remains unmeasured. Translation can use downloaded local models or an explicitly selected cloud text provider with your own key. See the historical [benchmark](https://github.com/Eren-Tian/LectureRelay/blob/0c59144aa950e213def3c5f2b4df441bdcbffadc/docs/testing/local-stt-benchmark-v0.2.md) and [installed acceptance](https://github.com/Eren-Tian/LectureRelay/blob/0c59144aa950e213def3c5f2b4df441bdcbffadc/docs/testing/installed-acceptance-v0.2.md), and the newer [local AI evaluation](https://github.com/Eren-Tian/LectureRelay/blob/0c59144aa950e213def3c5f2b4df441bdcbffadc/docs/testing/local-ai-v0.3.md). Earlier GUI model download/load and isolated native download/cancel/install/hash/load/remove tests passed; this settings update does not claim a new installed GUI download/cancel/removal test.
