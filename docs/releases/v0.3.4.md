# LectureRelay 0.3.4 — Classroom controls and local caption reliability

Windows preview candidate. Install the Windows EXE to use the application; developer tools are not required. Models remain separate downloads. The update preserves the existing library and settings.

- Fix the Windows Caption window freeze; add a close button and keep recording controls responsive while opening it.
- Permanently delete an individual lecture from course history or replay, with a named dialog and typed `DELETE` confirmation. Course materials and other lectures stay available.
- Guide first-time users through caption models, local-provider selection, microphone/system audio and starting a lecture. Download failures and disabled controls explain their state and support retry.
- Improve Quiet Mode CPU allocation and reduce translation CPU contention. Prioritize speech when it falls behind, bound waiting translation work and allow Pause translation / Resume translation without stopping recording.
- Show current English processing delay and a Full performance action when needed. Unfinished translations remain visible and can be completed after class.

See [verification and limitations](https://github.com/Eren-Tian/LectureRelay/blob/0c59144aa950e213def3c5f2b4df441bdcbffadc/docs/testing/classroom-fixes-v0.3.4.md). Local translation still waits for finalized speech and inference; this is not a claim of instant subtitles or verified accuracy for every subject and computer. The preview remains unsigned.
