77 项 desktop Rust 单元测试和 1 项环境测试通过，Clippy 无警告；TypeScript、7 组真实 React 组件回归、格式、仓库结构和资源检查通过。组件使用可控原生响应，不代表真实音频或云端验收。13 项依赖硬件、下载或真实模型的 opt-in 测试未在普通测试命令中执行。

总结配置独立、默认关闭。窗口只取新定稿英文和完整 segment，空输入不请求；输入快照、覆盖 IDs、引用校验、重启恢复、编辑过期、单任务、取消和 provider 限流等待均有回归。录音保存不等待总结；模型及数据清理不能与总结争用资源。任务 future 中途退出也会将未完成卡片标成失败，不会覆盖已完成结果。

## 真人素材与真实服务

使用 [MIT OCW 9.00，Fall 2004，Lecture 1](https://ocw.mit.edu/courses/9-00-introduction-to-psychology-fall-2004/resources/mit9_00f04_lec01_trimmed_mp4/)，讲者 Jeremy Wolfe。连续 01:00–06:00，mono 16 kHz PCM16，不改变语速，无 TTS。五分钟 WAV SHA-256：`656CE131A8B7999B4553BEC210FC84862D25BC790E45CE80C17AEB266AC448F3`。原始素材、完整转录、数据库备份和采样数据保留在忽略的 `target/`，不分发。

用户在应用内保存 Groq Key，连接生成测试状态通过。一张实际 `openai/gpt-oss-120b` 卡片在录音过程中完成，覆盖录音 00:20–04:32、20 段英文、4 条中文要点；所有引用对应真实输入 IDs。课程内容和“民间心理学”的概括可追溯，但一条关于“爱”的讨论被概括成“目前仍不明确，存在不同解释”，超过该片段支持的程度。提示词已强化讲师归属、假设和讨论性问题的区别；引用存在不等于结论正确。

随后冷启动手动整理同一课堂 04:34–05:07 的四段末尾英文时，卡片停在 running 而后台已不忙。隔离子进程回归复现了真实原因：`reqwest` 的 `rustls-no-provider` 路径未初始化 TLS provider，在构造客户端时 panic，尚未发出 HTTP 请求。本地模型或下载曾偶然初始化它，掩盖了正常使用中的冷启动缺陷。原生云端适配器现显式初始化已有 ring provider；完成守卫将未完成卡片标成失败，启动恢复仍保留原文。

最终安装版在启动本地模型之前，对相同四段英文完成了一次用户授权的 Groq 冷启动复测：点击重试至完成 1,104 ms，4 条中文要点、引用合法，原文相同。未再调用连接测试或进行额外云端重试。该卡片仍有泛化标题、把“晨起后感受到情感”的首句单独列成琐碎要点，以及“disembodied”字面翻译的问题；因此功能验收通过不代表总结质量已充分合格。此前切换本地 Qwen 重试同一尾段也成功（调试诊断版本约 69 秒），释义同样需结合原文核对。此次不宣称任一候选已通过完整课堂准确率验收。

第一轮原定关闭总结的观察在约 286 秒因界面切到设置页而中断；录音继续保存，之后正常停止，WAV 时长 533.27 秒。自动化脚本已补回到当前录音页再停止的收尾逻辑。该轮混入总结开关操作，不作为纯关闭总结的性能基线。设备报告过一次 discontinuity，但未报告影响时长；不能推断为丢失多少声音，也不能据此证明音频绝对无损。
