# 实时课堂总结

实时总结独立配置，英文识别和翻译仍按原有设置运行，不需要登录 LectureRelay。实时总结默认关闭，可选 Groq 或 OpenAI。0.3.10 为降低课堂功耗停用了本地 Qwen 实时总结；旧的本地总结设置升级后自动关闭，不会自动启用云端或上传文字。已有卡片、原文、手写笔记和下载的模型会保留。

## 用 Groq 开始

1. 打开 **设置 → 实时总结**，点击 **获取 Groq API Key**，前往 <https://console.groq.com/keys>。在 Groq 创建账户并生成 Key；这与 LectureRelay 免登录使用相互独立。
2. 将 Key 粘贴到应用密码框，点击 **保存 Key**。完整 Key 只写入 Windows Credential Manager，输入框随后清空。
3. 点击 **测试总结连接**。应用发送一小段固定测试文字，让选定模型生成 JSON 并校验格式及引用；仅保存 Key 不代表权限、模型或额度可用。
4. 阅读并勾选文字上传说明，再点击 **启用实时总结**。上传范围为本段已定稿英文及课程背景、术语；这一功能不上传录音。

默认评测模型为 `openai/gpt-oss-120b`，不是质量保证。高级设置允许更换支持 JSON Schema 的模型，换模型或 Key 后必须重新测试。生成的要点仍需与原文核对。

Groq 免费额度按账户及组织计算，有请求和 tokens 限制，不是无限使用。应用不提供开发者 Key、不代理请求，也不自动为用户付费。可打开 **查看账户额度** 和 **查看服务商数据政策**；正常推理与异常情况的数据保留规则以服务商政策为准。

## 课堂中的用法

- 右侧 **课堂要点** 默认每四分钟整理一段新定稿英文，可设为两分钟或五分钟。只按完整原文片段分段，不把临时字幕作为正式证据；静音或没有新英文时不发送请求。
- **立即总结** 可提前整理当前已收集的英文。一次最多一个总结请求；已经覆盖的原文不会产生重叠的新卡片。
- 卡片保留标题、三至五个要点、原始时间范围及英文引用。点击引用可回听；录音期间的片段回听最多六十秒。使用系统声音采集时，播放回听也可能被再次录入，请自行选择回听时机。
- AI 卡片与手写笔记独立。只有点击 **加入我的笔记**，才把要点追加到现有笔记草稿；仍由你决定是否保存草稿。
- 停止录音立即走原有录音保存流程，不等待总结完成。已经发出的总结可以继续完成；短于间隔的末尾英文会提供 **整理剩余片段** 入口。
- 关闭总结会取消未完成请求，保留英文和已完成卡片。失败卡片可单独重试。网络、额度或模型错误都不能停止录音。
- 限流遵循服务商的 `Retry-After`，且不会自动重发失败的云端请求。未完成窗口得到明确提示，新英文继续保存。
- 后续追加字幕不使旧卡片过期；修改卡片引用的英文、时间范围或辅助语言后，卡片会显示 **原文已更改**，可重新整理。重启后已完成卡片仍在，进行中的卡片会变为可重试状态。

## 其他模式

OpenAI 默认使用 `gpt-4o-mini`，设置流程相同。OpenAI API 用量与 ChatGPT 订阅分开计费；未保存的完整 Key 无法再次查看，应在官方控制台创建新 Key。本轮不优先增加 Gemini。

本地 Qwen 不再用于实时总结，也不会自动处理剩余课堂片段。无需下载 Qwen 就能使用 Groq 或 OpenAI 实时总结。切换到云端仍须自行保存 Key、测试连接、确认文字上传并启用。

课后完整总结、深度复习和问答继续使用原有学习工具；不会因为启用实时总结而解除录音期间的大型复习任务保护。
