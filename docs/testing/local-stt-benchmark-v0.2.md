## Method and limitations

Hardware: Windows x64, Intel i9-13900KF, 32 logical processors, 64 GiB RAM, NVIDIA RTX 4090; installed driver 616.92 reported CUDA 13.4. This is not an ordinary laptop. Quiet experiments constrain Nemotron to four available logical processors; Moonshine and Whisper use two software threads. Affinity and thread count are different controls. CPU percentages are normalized across 32 logical CPUs.

Five clips total **95.302125 seconds / 175 normalized reference words**: published JFK speech (11 seconds / 22 words), plus four Microsoft David Desktop SAPI synthetic clips for lecture-style English, GIS, computer science and biology. Synthesis uses rate -1 and is converted to 16 kHz mono PCM16. These clips cover requested vocabulary, but do not cover room noise, accents, microphone distance, overlapping speech or a held-out natural lecture corpus. SAPI pronunciation of acronyms can itself be wrong. Do not infer that a 0.57-point WER difference generalizes.

WER uses lower-case ASCII words/digits, removes apostrophes and ignores punctuation, then counts substitutions/deletions/insertions. Literal acronyms/numbers are not semantically normalized. The technical metric is **exact phrase miss rate over 17 reference phrases**, not a semantic technical-term WER. `Geo A I` versus `GeoAI`, or `nine` versus `9`, can be penalized despite equivalent meaning. This limitation is retained rather than changing normalization to favor an engine.

Process measurements sample at 100 ms. CLI measurements include the Python benchmark parent and its child tree; native streaming measurements target the worker PID. CPU averages in the table are averages of per-clip active inference averages. RAM is peak sampled working set, not total installed memory. RTF divides measured computation/CLI wall time by audio duration; streaming feeds in this short test are accelerated rather than real-time playback. Initialization is excluded from native compute RTF, but included in CLI wall RTF. Zero/absent metrics mean **unmeasured**, not zero resource cost.

Mean streaming computation averages per-clip means; no p95/finalized-segment end-to-end latency was collected. Initial native first-partial computation averaged ~581 ms, max ~851 ms. With two seconds of accumulated audio, first text is approximately **2.58 seconds plus checkpoint/poll/UI delay**. This is an estimate from measured components, not a measured screen latency. The native load handshake was ~38 ms warm-cache; lazy work may happen on first feed, so this is not a cold-start guarantee.

GPU runs returned CUDA backend success on all five clips. Process-attributed GPU utilization/VRAM were not captured; other GPU applications were active. Global GPU readings are not presented as LectureRelay consumption. The shipping app uses CPU only. Fan noise, energy use, laptop performance and full WebView2-inclusive CPU/RAM remain unmeasured.

Final Nemotron/Parakeet text generally capitalized/punctuated the clean clips; pauses did not always align with intended sentence boundaries. Moonshine stream text was less consistent and the 8-second endpoint policy lost words, particularly in CS (37.5% clip WER). Insertions alone cannot prove or disprove hallucination. No systematic silence/noise hallucination score was collected. App span IDs/cursors are designed to prevent duplicate saves; short benchmarks do not establish perfect sentence boundaries.

## Course glossary experiment

Two comparisons were run: official Nemotron CLI with eight boosted phrases, and the native C API with 17 multi-domain phrases at boost 3. Native RNNT speech-context support was checked against the actual header/configuration; it does not require a Flashlight/KenLM decoder for this model. With/without boosts produced **identical text**. Native WER stayed 6.29%, phrase misses 4/17; CLI WER stayed 6.86%. There is no observed benefit or harm on this set.

The native bias run overlapped the endurance worker on the same four affinity processors. Its CPU/latency values are confounded by contention and must not be interpreted as a boosting optimization or overhead measurement. Accuracy comparison remains valid. Production passes course source terms, bounded to 64 phrases/16 KiB; descriptions and preferred translations do not become native ASR prompts.

## Reliability and actual 90-minute soak

Moonshine reused-session experiments failed three times after roughly **199–201 seconds** with native code 18 (`OUTPUT_TRUNCATED`), in batch and streaming attempts. WAV/checkpoint evidence survived. This rejects the tested transcribe.cpp 0.2.4 integration for v0.2, not every Moonshine implementation or future runtime version.

Nemotron completed **5400.5998 wall seconds**, using real-time-paced synthetic/public PCM, a preserved native-worker snapshot with the same CPU/chunk/endpoint policy, independent WAV/checkpoint writing and SQLite finals. Translation pressure was simulated by queue delay; no translated text/provider calls were simulated as real outputs. This was **not CPAL capture, WebView2/React, or a real-classroom 90-minute acceptance test**.

## Packaging, licenses and selection

Bundle the pinned Windows CPU SDK, native worker and complete upstream notices; download weights from the pinned official NVIDIA repository after installation. SDK SHA-256 is `5e4ea81046012edcd77fd8848de8eefb5a4ba38cc26f52eb544ab184695a75d6`; CUDA archive used only experimentally is `ba024204e76ca2fa4eefa8787506c3c49e418147f627f60cf9206a582b60089c`.

NeMo-Speech.cpp is Apache-2.0 with transitive notices retained. Its notice list includes optional components with other licenses, including optional KenLM/Flashlight paths; do not describe every possible SDK build as Apache-only. The pinned CMake default disables Flashlight/KenLM. The official CPU artifact has no KenLM DLL or installed Flashlight/KenLM license subtree, consistent with that disabled path; its complete license tree is preserved. See [pinned build options](https://github.com/NVIDIA/NeMo-Speech.cpp/blob/v0.1.0/CMakeLists.txt). Nemotron weights use the [NVIDIA Open Model License](https://www.nvidia.com/en-us/agreements/enterprise-software/nvidia-open-model-license/), with use conditions and required license/notice distribution; it is not MIT/Apache. The unmodified license PDF and NVIDIA notice ship with the runtime and are copied beside installed weights. Parakeet's CC BY attribution and Moonshine/Whisper MIT notices would need preservation if those artifacts ship; they currently remain development-only.

Selection prioritizes stability, live usefulness and packaging over a tiny WER difference. Nemotron offers actual streaming, native Windows support, contextual API and a passed 90-minute native soak. Parakeet has no demonstrated accuracy advantage over the selected native path on this set and would add another model plus traceable refinement UI. Moonshine needs its observed session failure resolved before Quiet exposure. Whisper remains a useful lightweight reference. Secondary native candidates remain investigated but unbenchmarked.
