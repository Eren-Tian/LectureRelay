# LectureRelay 0.3.0 — Local AI preview

This preview adds offline translation, summaries and full-class review to the Windows application. Install `LectureRelay_0.3.0_x64-setup.exe`; end users do not build the source or install Python, Ollama or developer tools. The installer includes CPU inference runtimes. Model weights are optional separate downloads in **Settings → Local AI**.

## What's available

- Nemotron Streaming EN 0.6B remains the local English speech model.
- Hy-MT2-1.8B Q4_K_M translates English into Chinese, Japanese or Korean. Qwen3.5-4B Q4_K_M is an alternative translation choice.
- The same Qwen download supplies summaries, source-linked Q&A and **Review the whole class**, which accepts user instructions and processes all transcript sections. Generated notes are separate saved versions and preserve manual notes.
- Speech, translation and study choices are separate. Fresh text settings use local inference; existing explicit cloud settings survive upgrades. Local mode does not fall back to cloud. Optional cloud providers still require the user's own key.
- Quiet Mode gives all local AI a shared budget of up to four logical CPUs. Study starts after live processing ends. Workers are released after completion or cancellation; remaining AI work after stopping recording has a separate status.
- Model downloads support progress, cancellation, fixed revisions, SHA-256 verification and independent removal. All three models need about 4.3 GiB of disk space, plus working memory, app files and recordings.

See [setup](../user-guide/local-ai.md) and [model/runtime provenance](../licenses/native-runtime.md). The Qwen file is an attributed Unsloth conversion of the Apache-2.0 model. No CourseDude binary or wrapper is bundled. Bergamot remains a development comparison, not a shipped feature. This release generates text, not images.

## Evidence and limits

Normal Rust tests, Clippy, frontend type checking/build, formatting and repository checks passed. Opt-in checks exercised actual CPU models, download cancellation/hash verification, worker authentication/crash cleanup, cancellation and isolated native WebView workflows. A 50.74-second real system-audio GUI run completed local transcription/translation, pause/resume, stop and replay. The GUI run used a debug native application, not the installed release. Packaging verification is recorded separately on the GitHub release.

The small translation sample found terminology and negation errors, particularly in Hy-MT2's Japanese/Korean output; Qwen also made a summary interpretation error. These are preview candidates, not accuracy-certified defaults. First translated text in the cold debug GUI run appeared after about 44 seconds; it is not a passed real-time latency target. See [full evidence and measurements](https://github.com/Eren-Tian/LectureRelay/blob/0c59144aa950e213def3c5f2b4df441bdcbffadc/docs/testing/local-ai-v0.3.md).
