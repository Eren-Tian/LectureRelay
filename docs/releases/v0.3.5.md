# LectureRelay 0.3.5 — 中文界面

课程、课堂历史、实时字幕、回放、学习工具和全部设置页面改为自然的简体中文，包括首次设置、操作状态、错误提示和无障碍标签。安装器、原生文件选择窗口、字幕窗标题及启动失败提示也使用中文。

Nemotron、Hy-MT2、Qwen、OpenAI、Groq、API Key、CPU、PDF、Markdown、JSON、SRT、VTT 和许可证名称保留英文。课程名称、背景、术语、英文转录、用户笔记和 AI 内容不因界面语言而改写。学科、语言、处理任务和导出格式使用中文显示，存储标识和 IPC 合约保持兼容。

永久删除课程或单节课堂记录需要输入“删除”；清空资料与模型需要输入“清空全部数据”。取消确认不会执行删除。录音异常的缓冲区和采样数量、模型名及处理进度仍完整保留在中文提示中。

本版本包含 [0.3.4 的课堂控制和识别调度修复](v0.3.4.md)。中文界面验证不代表新的模型准确率或长时录音验收，参见 [验证范围](https://github.com/Eren-Tian/LectureRelay/blob/0c59144aa950e213def3c5f2b4df441bdcbffadc/docs/testing/chinese-ui-v0.3.5.md)。这是本地候选版本，发布状态以 GitHub Release 为准。
