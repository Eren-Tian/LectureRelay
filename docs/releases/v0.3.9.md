# LectureRelay 0.3.9 — 实时课堂要点

- 新增独立的实时总结设置与课堂卡片，默认关闭，默认四分钟，可选两分钟或五分钟，也可立即整理新定稿英文。
- Groq 为推荐的可选云端入口，默认候选 `openai/gpt-oss-120b`。保留 OpenAI 与本地 Qwen，不改变本地语音、翻译或原有学习工具。
- 获取 Key、密码框保存、实际生成测试、上传说明和启用按钮组成完整配置流程。Key 沿用 Windows Credential Manager，真实请求沿用原生 HTTP；没有共享 Key 或服务端。
- 卡片保存英文快照、真实时间范围和可核对的引用。只有用户明确追加时才写入手写笔记草稿；新增字幕不使已完成卡片过期，原文修改后提示重新整理。
- 总结请求单独管理，一次一个。录音停止不等待总结；失败、限流、设置取消和重启均保留原文及明确状态。末尾片段可以课后整理。
- 本地总结复用 Qwen，最多两条计算线程、较低进程优先级、全局共享安静模式 CPU 范围；字幕积压时让出资源，暂停后退避至少三十秒。
- 保留已有中文界面、配色和对比度，新增片段回听与总结设置入口。安装方式仍为 Windows x64 EXE，无需用户构建。

AI 要点可能错误，引用校验只能证明所引用的原文存在，不能证明每个结论正确。当前候选不宣称为最佳模型；普通笔记本功耗和 90 分钟完整课堂验收仍需单独进行。

使用方法见 [实时总结](../user-guide/live-summaries.md)。
