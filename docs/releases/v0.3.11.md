# LectureRelay 0.3.11 — 设置整理与状态可靠性

- 设置主导航从十个平级入口整理为六类；首次设置独立保留。声音与字幕放在一起，AI 功能、模型下载和实时总结集中管理，Key 与高级选项默认折叠。
- 外观、安静模式标注自动保存；其他偏好有修改时才显示保存栏。课程、字幕和学习功能的设置入口直接跳到对应位置。
- 设置组件按职责拆分，导航使用稳定标识；草稿合并有明确类型约束，并保留独立保存的运行时与总结偏好。
- 只读取当前声音来源的设备列表，避免一种设备读取失败影响另一种；迟到的设备响应不会覆盖新选择，并排除重复声音预览请求。
- 清空存储后的状态刷新失败会单独显示，保留原始清理错误及输入确认要求。
