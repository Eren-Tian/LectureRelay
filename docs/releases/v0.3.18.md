# LectureRelay 0.3.18 — 回听播放器、讲话人标注、笔记导图与课程归档

## 回听

- 课堂记录页有了自己的播放器：播放、进度条、±10 秒和倍速，支持空格与 ←/→ 快捷键。字幕跟随播放滚动，手动滚动后停止跟随，点“跟随播放”恢复。
- 没听完的课堂记录会提示“从 mm:ss 继续”，点击后才跳转；首页“继续学习”列出最近没听完的三节课，卡片底部显示进度。
- 选中字幕或学习工具里的文字可以“问 AI”，选中较短的词语还可以“加入术语表”。
- 字幕上方列出最多十个关键词，点击即可筛选字幕。关键词在本机统计，不调用模型。
- 两段字幕之间相隔 30 秒以上时，会标出这段空白的时间和时长；录音后半段尚未转写时也会标出，点击时间即可播放。
- 课堂记录卡片和课程页的课堂列表会标出“未转写”或“部分转写”。

## 讲话人

- 鼠标移到一段字幕上，点“+ 讲话人”即可标注老师、学生或任意名字，也可以一次给同一个人的所有段落改名。导出的字幕、Markdown 和 JSON 都会带上讲话人。
- “识别讲话人”用本地 Sortformer 模型自动把字幕标为“讲话人 1、讲话人 2…”，已手动输入的名字会保留。模型可选，在“AI 与模型 → 本地模型”下载，约 140 MiB，许可为 CC BY 4.0。

## 笔记

- 笔记支持表格、任务列表和删除线，编辑框上方有格式栏（标题、加粗、斜体、删除线、列表、任务列表、引用、表格），并支持 Ctrl+B、Ctrl+I、Ctrl+S。
- “预览草稿”显示尚未保存的草稿。
- 笔记预览可在“文档 / 导图 / 自测”之间切换：导图把标题和列表画成树状图；自测把每个标题做成一张卡片，回忆后再显示内容，最后可以只重练没记住的卡片。导图和自测都在本机生成。
- 问答的回答可以“加入我的笔记”或复制。

## 录音与导入

- 录音设备断开时，会在 5 秒内自动切换到系统默认设备，继续写入同一段录音，并在回听时标出切换位置。上课时点击状态栏里的设备名，可以手动切换录音设备；新设备无法启动时继续使用原设备。
- 录音因设备故障停止后，可以点“保存并继续录音”，在同一门课里换一个设备继续录。
- 把音频或视频文件拖到首页或课程页即可导入；导入对话框也接受直接指向音视频文件的 https 链接，例如课程平台的下载链接。不支持 YouTube 等视频网站页面。

## 翻译与课程

- 翻译语言从中日韩扩展到 20 种，包括繁体中文、越南语、泰语、阿拉伯语、西班牙语、法语、德语等；阿拉伯语、波斯语和乌尔都语从右向左显示。语言列表先列常用语言，其余按拼音排序。本地翻译只评测过中文、日文和韩文。
- 课程页新增“归档课程”：归档的课程从侧栏和课程列表移到下方折叠的“已归档”分组，课堂记录和资料保持不变，可随时取消归档。

## 升级说明

运行安装包即可升级，课程、课堂记录及下载的模型会保留。此版本仍为未签名的开发预览版。

**数据库结构有变化**：首次启动时会依次执行迁移 006（翻译语言）、007（讲话人标注）和 008（课程归档）。迁移后的数据库无法再用 0.3.17 或更早版本打开；如果想保留回退到旧版的可能，请在升级前退出应用并备份数据文件夹。

新增的第三方组件：前端依赖 remark-gfm 4.0.1（MIT），以及可选下载的 NVIDIA Sortformer 4spk v2 模型（CC BY 4.0，安装时写入 NOTICE-Sortformer.txt）。语音识别和翻译模型版本没有变化。
