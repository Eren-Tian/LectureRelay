# LectureRelay

LectureRelay keeps classroom recordings, source captions and learning material together. These terms distinguish saved evidence from unfinished or AI-generated work.

## Language

**Course**:
A collection of lectures with shared background, glossary and assistance language.
_Avoid_: Lecture, classroom recording

**Lecture**:
One recorded or imported class session with its own timeline and learning material.
_Avoid_: Course

**Final English segment**:
English accepted by the recognizer as a completed caption span. A user can still correct it later.
_Avoid_: Immutable transcript, final translation

**Translation preview**:
A provisional translation that may change as the speaker continues or a final translation arrives.
_Avoid_: Saved translation

**Deferred translation**:
Translation left for later while its English source remains available.
_Avoid_: Lost recording, lost transcript

**Note draft**:
Uncommitted changes to a user's notes that can be recovered without replacing the saved notes.
_Avoid_: Saved notes, AI note version

**Live summary card**:
AI-generated key points tied to a specific span and version of the lecture's English source.
_Avoid_: Manual notes, complete lecture transcript
