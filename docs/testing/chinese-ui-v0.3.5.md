# LectureRelay 0.3.5 中文界面验证

验证日期：2026-10-05。此次验证针对界面语言、中文排版、显示状态与安装交付，使用当前 Windows 机器。

## 完成范围

首次设置、课程、课堂历史、实时字幕、回放、学习工具、全部设置分类、操作确认、已知系统错误、下载状态和无障碍标签采用简体中文。安装器、原生音视频及 PDF 文件选择窗口、独立字幕窗标题和启动失败提示使用中文。

模型、服务商及许可证名称保留英文，API Key、CPU、PDF、Markdown、JSON、SRT、VTT 等名称保持原样。原始英文转录、课程名称、背景、术语、笔记和 AI 内容不因界面语言改写。存储中的语言、学科、任务及导出格式标识保持兼容。

界面的永久删除确认输入“删除”，清空课堂数据与模型输入“清空全部数据”；原生删除接口仍使用原有确认参数。取消确认不会调用删除接口。动态录音警告中的丢失数量及模型下载提示中的模型名称保留在中文提示中。

## 验证边界

模拟 IPC 的组件测试不等于原生 WebView 验收，原生界面检查使用隔离 debug EXE，不等于安装版长时录音测试。本轮没有重新测试模型推理质量、实时翻译延迟、付费 API、硬件断开或 90 分钟录音。此前课堂可靠性证据见 [0.3.4 验证报告](classroom-fixes-v0.3.4.md)。
