# LectureRelay v0.2.0 — product iteration

Historical iteration report. The later [preferences update](v0.2.0-preferences.md) supersedes the fixed appearance/Quiet Mode descriptions and installer checksum below.

Date: 2026-10-02. Windows x64. This focused iteration improves Settings, bilingual classroom reading and the phoenix identity. [Coursedude](https://coursedude.ai/en) informed the hierarchy and paired-caption reading order; artwork, colors, copy and implementation are original to LectureRelay.

## What changed

Settings now has eight categories and one shared preferences draft. Switching categories retains edits; saving updates them together. This removes the two independent whole-settings forms that could overwrite each other's values. All interface labels remain English.

| Category           | Contents                                                                                                                   |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------- |
| General            | Default translation language for new courses, warm-light appearance, Quiet Mode explanation                                |
| Audio              | Default source, preferred microphone and system playback device, refresh devices                                           |
| Live Captions      | English/translation visibility, both font sizes, automatic following, labelled sample preview                              |
| AI Providers       | Independent speech selection, shared text provider for translation/notes/Q&A, live-translation switch, advanced text model |
| Local AI           | Installed/download state, progress/cancel/remove, model details and setup guidance                                         |
| Data               | Library and model storage usage, library/export folders, database location, course trash/restore                           |
| Security & Privacy | Password-only key entry, saved-key status, connection test and local/cloud explanation                                     |
| About              | New identity, version, license and source-publication status                                                               |

The existing warm theme, Quiet Mode and single supported speech model are presented honestly; there are no placeholder theme/model switches. Storage counts exclude linked folders. Preferences remain backward compatible; saved visibility, font sizes and translation choices are retained. Fresh caption defaults are 22 px English / 18 px translation, with live translation enabled but the cloud provider disconnected.

## Live translation and reading

1. Local recognition publishes partial English immediately. Finalized English is saved to SQLite before translation is queued.
2. When **AI Providers → Translate during class** is enabled and the chosen text provider has a saved key, the existing official OpenAI/Groq adapter translates finalized sentences using the course's Chinese, Japanese or Korean language and context. Notes and Q&A use that same text provider.
3. Each translation is matched to its original segment ID, saved, and published beneath its English paragraph. Partial/final rendering retains paragraph identity. Native publications serialize caption snapshots so an older English-only snapshot cannot replace a just-saved translation.
4. Pending, missing-provider and deferred translations have explicit states. Invalid/missing results, queue overflow, timeout and database write failure leave English intact and allow after-class retry. Translation warnings survive subsequent speech updates. After Stop, the replay view explains that audio is saved while remaining work finishes.

The reader maintains a visible paragraph anchor while the student scrolls up, including when translations change paragraph height or old history is trimmed. **Jump to Live** returns to the newest caption. The classroom uses its available height and keeps Pause/Resume and **Stop & save** outside the scrolling caption area. Full transcripts remain in replay; live history stays bounded to 200 finalized segments.

To enable bilingual use, choose the speech/text providers in **AI Providers**, enter the real key directly in **Security & Privacy**, enable **Translate during class**, and keep **Live Captions → Show translation** on. Existing courses retain their own language, independently of the default for new courses.

## Verification and limits

The detailed recording and translation results below were measured before the follow-up branding cleanup. That cleanup only changes UI copy/layout. TypeScript, formatting, release packaging and installed-page checks passed: Courses, Settings, About and the 880×620 course view each show exactly one logo beside the app title, none of the removed slogans, and no horizontal overflow. The recording/API suites are not rerun for it. Evidence: `target/product-iteration/branding-cleanup-ui.json`.

- TypeScript, production build, Clippy with warnings denied and formatting checks passed. Rust: 20 desktop tests plus one environment test passed; five opt-in hardware/download/credential tests were not rerun. New coverage checks all three target-language strings in the real database, ID matching, rejected writes, failure delivery state and bounded shutdown history.
- The real `LiveCaptions` component passed deterministic Edge fixture tests for Chinese/Japanese/Korean, English-over-translation order, partial-to-final DOM identity, delayed-translation scroll stability, trimmed-history anchoring, Jump to Live, disabled auto-scroll, failure text and a compact viewport. These use **synthetic translations**, not cloud authentication.
- The final NSIS package installed silently and launched its real WebView2. Native GUI acceptance passed all eight categories, shared drafts, device/language persistence, restart, real system audio → local English, missing-provider explanation, history/Jump to Live, pause/resume/stop, saved-lecture restart and timestamp playback. The 1180×780 and 880×620 classroom checks kept controls and the latest caption inside the viewport. Original preferences were restored. A four-character invalid key was rejected locally and its password field cleared, without credential storage or a provider request.
- Executable, installer and uninstaller each contain all six canonical ICO images. The installed EXE matches the release payload. Repository hygiene found 202 source files, 32 frontend modules, no flagged secret patterns and no broken links/import issues; this is not an independent security audit.
- The final short recording contains 33.55 seconds and four finalized segments. All 1,610,400 mono PCM16 frames at 48 kHz were readable; real timestamp playback also passed. A single dropped/discontinuous-buffer warning was reported, so this check does not claim artifact-free capture or classroom recognition accuracy.

No paid cloud tests were run, as requested. Authenticated translation/STT/notes/Q&A remain unverified; a saved key is not represented as a verified connection. This iteration does not claim to fix the WebView2 memory growth seen in the earlier 90-minute run, and that run was not repeated for this binary. Ordinary-laptop noise/power acceptance remains outstanding. The package remains unsigned; project-wide licensing and a public GitHub repository are not finalized.
