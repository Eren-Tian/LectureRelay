# LectureRelay 0.3.15 — 模型只保存一份

- 每个本地模型只在 `%LOCALAPPDATA%\LectureRelay\models` 保存一份，课堂字幕、翻译、补全转录和课后学习都使用这份文件。
- 修正模型被重复下载的问题：由其他应用（例如 Codex 桌面版）启动 LectureRelay 时，Windows 会把新文件写入该应用的私有目录，正常打开的 LectureRelay 看不到这些文件，于是再次下载同一模型。现在 LectureRelay 会识别这种情况并拒绝在其中下载，提示从开始菜单打开后再下载；已下载的模型照常可用。
- 判断模型是否已安装时只核对模型本身（版本号与 SHA-256），不再受运行环境版本影响，以后升级运行环境不会让相同的模型重新下载。
- 启动时清理下载中断后残留的临时文件。

运行安装包即可升级，课程、课堂记录及下载的模型会保留。此版本仍为未签名的开发预览版。数据库结构、模型版本和第三方依赖均未改变。
