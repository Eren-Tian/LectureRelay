# LectureRelay 0.3.12 — 提示准确性与内部结构整理

- 一批原先只显示“操作未完成，请重试”的提示，现在显示准确的中文说明，涉及实时总结读写、服务商错误、退出时中断的任务等。原生提示统一为英文，由中文目录翻译；仓库检查会拒绝缺少翻译或已经失效的条目。
- 指向已移除菜单“设置 → 本地 AI”“AI 服务商”的提示，已更正为“设置 → AI 与模型 → 本地模型”等当前位置。
- 导入音视频与其他 AI 任务一致，会等待模型下载完成。云端实时总结不使用本地模型，因此不再阻止下载或删除模型。
- 偏好设置中出现当前版本无法识别的值时，回退为默认值，不再导致设置读取失败。无法识别的实时总结服务会被关闭，不会被改为云端服务。
- 内部整理：实时字幕拆分为识别与翻译两个模块；“正在录音、处理中、下载中”等互斥判断集中到一处；设置与状态字段改为类型化；界面文字全部进入中英文目录；架构文档按当前代码重写，移除一次性验收脚本与旧报告。

运行安装包即可升级，课程、课堂记录及下载的模型会保留。此版本仍为未签名的开发预览版。数据库结构、模型版本和第三方依赖均未改变。
