# LectureRelay 0.3.7 candidate

The classroom workspace now opens to **课堂要点**, rather than an empty manual note editor. During recording it collects finalized captions into source sections spanning approximately two minutes, with shorter sections for large text. These are labelled as source content, not AI summaries.

After recording and remaining caption work finish, **生成课堂要点** runs the configured local Qwen3.5-4B model. Each completed section is persisted and displayed immediately, even if later generation fails or is cancelled. **继续整理** reuses completed work. No third model is scheduled while recording; no hosted service is used by this panel.

Each card shows its evidence time range, expandable original transcript and a playback action. **加入我的笔记** appends the selected section to the existing manual draft with a timestamp. Generated notes do not replace manual notes. Changes to the transcript or summary language mark old results as outdated. Long outlines are paged; all saved transcript segments are included, including those outside the recent caption window.

Existing user-directed deep reviews, note history, manual editing and export remain available under **我的笔记**. Summary instructions preserve the referents of criticisms and negations, forbid invented causal explanations, and omit uncertain cut-off claims; these instructions are not a guarantee of model accuracy. This release does not implement automatic live AI summaries or claim to solve transcription boundary truncation or all translation delays.

See [validation and scope](https://github.com/Eren-Tian/LectureRelay/blob/0c59144aa950e213def3c5f2b4df441bdcbffadc/docs/testing/classroom-summary-v0.3.7.md). Local candidate; GitHub publication is a separate step.
