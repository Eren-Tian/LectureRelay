# LectureRelay 0.3.2 — Data integrity and readability

**Windows preview.** [Download the EXE and checksum from GitHub Release](https://github.com/Eren-Tian/LectureRelay/releases/tag/v0.3.2). This release strengthens recording and saved-data handling and increases contrast in both Light and Dark themes.

- Repeated/stale Stop requests cannot overwrite a saved lecture. Concurrent snapshots and exports use independent temporary files with cleanup on failure.
- Imported recordings survive a database-finalization error. PDF attachment/loading has a bounded read.
- Audio diagnostics distinguish queue drops from device discontinuities, and saved recording warnings remain visible in replay.
- Notes resist duplicate clicks and save/edit races. Incomplete cloud responses cannot be presented as completed output.
- Text, form boundaries, selected navigation and editing controls are easier to distinguish. Disabled buttons keep readable labels.
- Installer verification uses the stable user installation directory and derives package paths from the version configuration.

See the [engineering review and validation limits](https://github.com/Eren-Tian/LectureRelay/blob/0c59144aa950e213def3c5f2b4df441bdcbffadc/docs/testing/engineering-audit-v0.3.2.md). The earlier [90-minute 0.3.1 run](https://github.com/Eren-Tian/LectureRelay/blob/0c59144aa950e213def3c5f2b4df441bdcbffadc/docs/testing/installed-acceptance-v0.3.1.md) remains separate evidence. AI semantic accuracy, laptop suitability and authenticated cloud workflows are not certified by this release.
