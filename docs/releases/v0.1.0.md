# LectureRelay 0.1.0 — first executable preview

## Implemented

- Calm sage / ivory / muted-gold shell: courses, course detail, live recording, lecture replay, settings. Original green/gold pixel phoenix SVG and Windows PNG / ICO branding.
- SQLite transactional migration, course create/edit/delete, subject/description/language, course glossary, lectures, timestamped bilingual segments, note editing, saved Q&A, preferences.
- Native WASAPI microphone selection and PCM16 WAV recording, pause/resume/stop, sample-based duration, level/warnings, one-second checkpoints and interrupted-recording recovery.
- Local lecture reopening, WAV replay, transcript seek, manual bilingual correction, Markdown notes and JSON / Markdown exports.
- Windows Credential Manager BYOK, masked status, replace/remove, safe errors and fixed official HTTPS provider destinations.
- OpenAI / Groq adapters for post-stop STT, Chinese/Japanese/Korean translation, structured notes, and lecture-grounded Q&A with reference snapshots. Chunk progress, retry and cooperative cancellation.
- Quiet Mode: no AI job or provider connection test during recording; one job at a time. OS file-sharing lock protects each data root from concurrent processes. Closing during recording asks to save first; startup errors use a sanitized native message.

## Partial

STT is post-stop, not real-time. Missing provider timestamps fall back to chunk spans. Q&A uses bounded bilingual keyword retrieval and a representative fallback for long transcripts, without semantic embeddings. Notes are one editable Markdown record; there is no revision history. Assistance content supports three languages while the UI currently uses Chinese. The cloud code is implemented and compiled, but no authenticated provider call was tested because no real key was supplied.

## Not implemented

Local STT / LLM models, true streaming captions, system audio loopback, automatic note/index scheduling, semantic search, quiz generation, login, sync, phone/Google integration, dark mode, configurable library migration, audio import, course trash recovery, app-level data encryption, signing or automatic updates. No inactive buttons pretend to provide these features.

## Storage and decisions

SQLite at `%LOCALAPPDATA%/LectureRelay/app.db` is authoritative. Windows Documents Known Folder contains `LectureRelay/Courses/<course UUID>/<lecture UUID>/{recording.wav,metadata.json,transcript.json,notes.md}` and `LectureRelay/Exports`. Native state/cache/model/log/temp/recovery paths are separate from installation and source caches. Keys only live in Windows Credential Manager. Course deletion removes indexed records but keeps files; import/restore of deleted indexes is not implemented. See [architecture](../architecture/overview.md) and [security](../../SECURITY.md).

## Validation on 2026-09-30

- TypeScript check and Vite production build passed.
- Rust workspace: 14 ordinary tests passed (13 desktop + 1 bundled SQLite), with 2 explicit opt-in tests excluded by default. The synthetic Credential Manager roundtrip test and isolated UI fixture preparation were also run successfully.
- Rust Clippy with `-D warnings`, rustfmt, Prettier, and environment doctor passed.
- Native Windows UI: opened course/glossary data, replayed the synthetic WAV using the native asset protocol, clicked a transcript timestamp, rendered manual Markdown notes, inspected settings, created a course through the real form, confirmed missing-provider guidance, and exported verified bilingual JSON and Markdown notes.
- Actual Yeti GX microphone: recorded, paused at 17 seconds, confirmed paused duration/level, resumed, then stopped and saved 40.32 seconds of mono WAV. Metadata marked completed and the recovery marker was removed. Restart showed both courses and lectures persisted. All test data used an isolated root under `target`; no cloud upload occurred.
- Final x64 release EXE was launched successfully with an empty production course library and verified Windows Known Folder paths. Isolated test data, including microphone audio, were removed after verification. The current-user NSIS installer built successfully. Install/uninstall on a separate clean Windows user, long lecture endurance, disk-full and device-removal acceptance are still outstanding. No signing or independent security audit was performed.

## Run / package

From the project root: `pnpm run doctor`, then `pnpm dev`. Build debug with `pnpm build:debug`; build release and NSIS with `pnpm build`. Existing setup remains `pnpm run setup`; no new system-wide runtime installation is required.

Installer: `target/x86_64-pc-windows-msvc/release/bundle/nsis/LectureRelay_0.1.0_x64-setup.exe`.

Executable: `target/x86_64-pc-windows-msvc/release/lecturerelay-desktop.exe`.

End users use the installer, create a course, select a microphone and save a lecture. AI setup is optional; see [provider setup](../providers/setup.md). Add a real key only in the application.
