# LectureRelay 0.3.17 — 课堂要点更醒目，设置和删除更简单

0.3.16 没有单独发布，它的课堂页改动也包含在这个版本中。

## 课堂要点

- 上课时最新的要点卡片排在最上方，并标为“最新”；进度条显示已收集的英文时长，满一个间隔就自动整理，不用滚动就能看到最近的总结。
- 要点文字更大，回听时间以小标签跟在每条要点后面；不再给已完成的卡片标注“AI 要点”。
- 课堂页更紧凑：录音状态移到课程标题同一行，英文识别正常时只显示一个小标签，出现问题时才显示提示；“暂停翻译”移到字幕标题旁。
- 字幕与课堂要点默认各占一半宽度，宽屏不再限制在 1080 像素；窗口较窄时仍保持两栏，更窄时可在“字幕 / 课堂要点”之间切换。
- 依照 Web 界面规范改进：学习工具标签页支持方向键切换并补全无障碍属性，动画只使用 transform 和 opacity，课堂页不再使用 9 像素的小字，状态、提示和字幕标题文字放大到 11–14 像素。

## 设置与界面文字

- 设置和课堂页的说明改得更短更直接，去掉重复的标题和多余的解释；上传内容、服务商收费和删除范围这几项限制各说明一次。
- “实时总结”统一改称“课堂要点”；“AI 与模型 → 功能设置”改名为“处理方式”。
- 课堂要点设置去掉了步骤列表和“工作原理”说明，Key 状态和获取 Key 的链接放在同一行；课堂页中点击“设置”即可在弹窗里修改。

## 删除

- 课程页的“删除课程”会直接把课程移入回收站，提示条中的“撤销”可以马上恢复。
- 删除一节课堂记录、从回收站永久删除课程，只需在确认框中确认一次，不再要求输入“删除”。
- “清空数据与模型”仍需输入确认词，确认词改为“清空”。

运行安装包即可升级，课程、课堂记录及下载的模型会保留。此版本仍为未签名的开发预览版。数据库结构、模型版本和第三方依赖均未改变。
